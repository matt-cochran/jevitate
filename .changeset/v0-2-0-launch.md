Jevitate v0.2.0: autonomous browser testing that turns discovered bugs into deterministic regression tests.

- **Reproduce, verify, lock in.** `verify-fix` replays a finding 3 times in fresh browser contexts and reports `intermittent` (exit 4) instead of a lucky `fixed`. A new finding ledger (`jevitate ledger add|list|verify`) keeps the repro material in the repo, so `jevitate verify-fix <fp>` works from a fingerprint alone. `regression capture` accepts failed success checks, network checks and declared-invariant violations as its oracle, never the engine's own refusals, and `regression run <id>` replays a committed regression.
- **One result contract.** Every strategy writes the same versioned result (`schemaVersion: 1`): `missionOutcome` is always the canonical verdict (a goal's own `succeeded`/`failed`/`exhausted`/`blocked` is in `goalOutcome`), `defects` holds every defect, and `hostHealth`/`environmentDegraded` tell a starved host apart from app findings. Code decides defects: an HTTP 5xx is a defect in every strategy, while a state flagged only by Jev's judgment is advisory. A run that proved nothing (too little coverage, a vacuous check, a starved host, an app that stopped answering, a usability job never completed) is `inconclusive`, never `clean`; an unreachable target fails in seconds.
- **One CLI contract.** One exit-code table for every command (`0` ok · `1` defects · `2` inconclusive · `3` hang · `4` intermittent · `64` usage/input error · `130`/`143` killed), a human summary by default and the unchanged `{v, ok, data | error}` envelope with `--json`, and every refusal as `error <CODE>: <message>` on stderr.
- **App-declared invariants.** `--invariants` checks your own rules (DOM, network, `never.response` and read-only probes, including authenticated probes and cross-actor isolation checks) around every action; `jevitate invariants validate` checks the file without a browser.
- **CI gate and reporting.** `jevitate check --suite` runs Journeys, goals, missions (whose items take every `explore` option), invariant sweeps and re-checks within a budget, writing JUnit and SARIF. `jevitate report`, `diff` and `baseline` give one deduped defect list and new / resolved / flaky classification.
- **Real apps.** Bound secrets typed by code, `--secret env:VAR`, TOTP, `--save-storage-state`, mission fixtures around every run and replay, authenticated queued missions via `targets.json`, backend log correlation, `--repeat`/`--min-agreement` voting, persona matrices, multi-actor missions, site policies for Journey runs, and a repo-local `.jevitate/` with shared Journeys.
- **Safer by default.** Session-ending, destructive and paid controls are refused unless you pass `--allow-destructive`; find-out goals are read-only unless you pass `--allow-writes`, and an off-site write passes only when it carries no credentials to an origin the app authenticates with; hang replays never re-send a paid write; secrets shown on the page are redacted; profile names and regression ids cannot escape their directories; runs are bounded by a page watchdog, and killed runs still write a result.
- **Better goal runs.** Network, persistence and visual-state checks with a vacuous-check rule, rich-text edits in `contenteditable`, find-out answers grounded in page text and form values that must actually answer the question, conversational-page handling, and usage with the full run cost (Jev priced by default).

Upgrading from 0.1.0: parse `--json` (human output is now the default); usage errors exit `64`; compare a goal's `missionOutcome` with `clean`/`defects-found` or read `goalOutcome`; `insufficient-exploration` is now `insufficient-coverage`; `--success` is refused on coverage/exploratory/adversarial/feature runs and enforced on usability; coverage, exploratory and `--feature` runs are scoped to the start route by default (`--scope app`/`--route` to widen); the default safety policy refuses destructive and paid clicks; `textIncludes` is case-insensitive; `verify-fix` exits 4 for intermittent findings; `ledger verify` with no entries exits 2; exploratory results are named `exploratory-*`; a bare `report`/`diff` reads only the current project's runs; `--real --fake-ai`, an unknown `--strategy` and re-capturing an existing regression id without `--force` exit 64; and `serverLogDefects`, `recordingPath`, `usage.usd` and `usage.jevPriceSource` are deprecated aliases. See CHANGELOG.md for the full list.
