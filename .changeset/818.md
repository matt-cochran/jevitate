`journey verify --mutate` now saves its full redacted report before it prints anything (#818). If stdout is lost, for example when an SSH session drops, the per-mutation and per-assertion evidence is still on disk. The report goes to `.jevitate/journeys/.verify/reports/<id>/<stamp>-<sha256 prefix>.json`, mode 0600 in a 0700 folder. It holds the engine identity, the Journey and proof hashes, and the report itself. The canonical `.verify/<id>.json` receipt records the file as `nativeReport: { path, sha256 }`, and `--json` output carries the same field with an absolute path. A file is written once and never replaced, and the 20 newest per Journey are kept. If the report can't be written, nothing claims a file: the receipt and the output carry `nativeReportError` instead, and a warning goes to stderr. A secret parameter's value never reaches the file, and a report that still contained one is not written.
