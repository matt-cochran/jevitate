`explore-author-journey` takes `--fixtures` (with `--before`, `--after`, `--fixture-identity`), set up before and restored after every take (#544). The Journey records `metadata.fixtures` (`{ file, specHash }`), and `journey run`, `verify --mutate` and `annotate` reuse it with no flag. Precedence is `--fixtures`, then the recorded file, then the environment's. A missing recorded file is refused with `E_FIXTURE_SPEC` before any browser opens; a changed spec runs with a warning and `fixtureDrift` in the result. MCP `author_journey` takes `fixtures` and `fixtureIdentity`. `explore-author-journey` also takes `--log-*` (backend-log) flags and `--allow-writes`; MCP `author_journey` maps `allowWrites` and omits the log flags, like `run_exploration`.
