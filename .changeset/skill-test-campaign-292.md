New built-in agent skill `jevitate-test-campaign` (#292), installed by `jevitate init` with the others: how to plan and run an end-to-end release test campaign — preflight, a jobs-to-be-done catalog with goal specs, discovery runs that draft Journeys, journey-anchored adversarial/exploratory missions, a small coverage pass, full-stack log evidence, collect-then-fix with `verify-fix`, the ledger and regressions, triage by exit code, budgets, `check` suites in CI, and the release gate. Includes job-spec and issue-register templates.
