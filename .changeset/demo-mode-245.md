Demo mode: watch a run (#245). Headless stays the default everywhere, `check`/CI included. `--headed` (or `JEVITATE_HEADED=1`) opens a visible Chromium for every `explore` strategy, `journey run`, `verify-fix` and `regression capture|run` — including hang-replay, observer and verify-fix replay sessions. `--slow-mo <ms>` sets Playwright's `slowMo` (a non-negative integer, else exit 64; 250 by default with `--headed`). `--record-video [dir]` (`explore`, `journey run`, `verify-fix`) records each browser context, headless too, into a per-run `<run>.videos/` folder next to the result; the contexts are closed before the result is written, and the files are listed as `videoPaths` (an additive field of the unified result schema, `schemaVersion` 1) and as `VIDEO` lines in the human summary. `--no-overlay` hides the on-page overlay of a headed explore run. `--headed` without a display (no `DISPLAY`/`WAYLAND_DISPLAY` on Linux) is refused before any browser launches (exit 64, suggesting `--record-video`); a headed `--repeat`/`--persona`/`--actor` run prints a one-line warning and shows every window. A `check` suite item takes `headed`, `slowMo`, `recordVideo` and `overlay`. Queued (`mission run`/MCP) missions stay headless. The adversarial and feature runners' unused `headless` option is gone: headedness comes from the `browser` option like every other runner's.
