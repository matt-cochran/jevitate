Releases publish the bytes CI tested (#534). A push to `dev` that passes the full suite packs both packages into a release-candidate artifact named after the git tree. Promotion PRs into `staging` and `main` reuse that verdict when their merge tree matches. A merge to `staging` publishes those tarballs to npm as `next`, and a merge to `main` moves `latest` to the same version without rebuilding. `jevitate --version` now also prints the tree hash (`x.y.z (commit <sha>, tree <tree>, built <time>)`), so a build packed from a dev commit matches the `main` commit that released it.
