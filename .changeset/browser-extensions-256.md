Browser extensions (#256). `--extension <dir>` (repeatable) loads an unpacked extension into the run's browser on every browser-driving command (explore strategies, explore-author-journey, journey run/annotate/demo, demo, verify-fix, check, ledger verify, regression capture/run, load run, source run, mission run, record); the mirroring MCP tools take an `extension` array (confined like every MCP path). The directory is checked (a manifest.json with manifest_version 2/3, name, version) and its extension id computed before any browser opens; a bad directory is a usage error (exit 64). Each session with extensions runs its own persistent Chromium context on a throwaway profile (headless: Playwright's full Chromium in new-headless mode, since the headless shell cannot load extensions) and proves each extension loaded before the run. Loaded extensions' `chrome-extension://<id>` origins — only those ids — are allowed, so a run can start at `--url chrome-extension://<id>/sidepanel.html` (a side panel, popup or options page is opened as a page in the same context) and the agent acts on its DOM; an unloaded id is refused (exit 64). Recordings gain an additive `extensions: [{id, name, version}]`; verify-fix (and `journey run` of a Journey recorded with extensions) refuses a different build with exit 64. See docs/extensions.md.
